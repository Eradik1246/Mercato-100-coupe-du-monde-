# Mercato-100-coupe-du-monde-
Mercato Coupe du Monde : choisis un pays, compose ton onze avec un budget serré (+ banc), pick tes tactiques ou écris ton plan de jeu avec les mots du foot, puis joue la Coupe du monde : poule, 5 tours, adversaires de plus en plus forts. Match en direct animé, corners, touches, sauvegarde de tes équipes.
